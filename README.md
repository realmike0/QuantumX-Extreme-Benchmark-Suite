# 🚀 QuantumX Extreme Benchmark Suite

**QuantumX Extreme** is a cutting-edge, high-performance 3D graphics benchmark and stress-test application. Powered by **WebGL 2.0**, **Three.js**, and custom volumetric shader raymarching algorithms, it is designed to push mobile devices, tablets, and desktop GPUs to their absolute limits.

---

## ✨ Key Features

- 🎮 **Real-Time Telemetry Suite:** Live monitoring of FPS, frame-time (ms), active geometry, voxel particle counts, and GPU draw calls with a collapsible HUD.
- ⚡ **Dynamic Hardware Diagnostics:** Automatic detection of GPU renderer strings, available system RAM, and CPU core concurrency.
- 🎛️ **Advanced Graphics Configurator:**
  - **Resolution Scaling:** Test across native 1080p FHD, 1440p QHD, 4K Ultra, and extreme 8K presets.
  - **Ray Tracing & Raymarching:** Adjustable volumetric reflection and shadow quality levels (Off, Low, Med, High, MAX).
  - **AI Super Resolution (DLSS / FSR Upscaling):** Toggle between Native, Quality, Balanced, and Performance upscaling profiles.
  - **Particle & Object Stress Sliders:** Dynamically scale up to 150,000 volumetric particles and 20,000 complex geometric meshes.
- 📱 **Cross-Platform Touch & Desktop Support:** Fully responsive landscape and portrait layouts with intuitive drag-to-rotate and pinch-to-zoom controls.
- 🔋 **Power & Thermal Estimation:** Real-time simulated wattage and thermal throttling monitoring based on hardware load.
